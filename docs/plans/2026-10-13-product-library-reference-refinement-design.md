# 产品库参考模板高还原重构设计

## 背景与目标

当前产品库已经能按基础 SKU 合并国家版本，但页面仍沿用旧中台的“大 Hero + 独立搜索面板 + 独立筛选面板 + 独立视图栏”结构，首屏纵向空间被大量占用。卡片内部又通过国家页签切换版本，并同时放置三类价格，导致用户既看不到同 SKU 的跨国比较，也难以快速扫读。

参考模板真正有效的部分不是颜色或圆角，而是“先比较、后展开”的信息架构：顶部工具集中在一个吸顶区域，卡片直接列出多个国家的主价格，更多国家和完整信息进入详情；字体等级克制，卡片 hover 只改变阴影，图片轻微放大，页面与区块仅做一次短距离入场。

本次目标是在不删除价格权限、库存、资料、资质、素材和组合 SKU 计算器的前提下，把产品库重构为可快速扫描、可跨国比较、交互安静且层级清晰的经营工具。

## 方案选择

采用“参考模板高还原结构 + 同舟业务增强”方案：

- 不做纯 CSS 修补，因为现有结构本身造成拥挤。
- 不做模板的逐字段照抄，因为模板只有单一分销价，无法覆盖同舟的分销成本、直营成本和销售价权限。
- 保留同舟的数据与权限模型，但把价格类型提升为全局口径切换，每张卡一次只展示一个价格口径；完整三类价格在详情矩阵中同时呈现。

## 页面结构

1. 顶部使用紧凑标题行，展示“产品库”、同步状态和同步时间，不再使用大型宣传 Hero。
2. 标题下方使用吸顶工具栏：第一行包含搜索、品牌、价格口径和视图；第二行包含带国旗与数量的国家筛选，以及当前 SKU 数量。
3. 卡片视图固定采用自适应 4/3/2/1 列，不再向用户暴露 4/6/8 密度选项。
4. 价格矩阵以 SKU 为行、国家为列，当前价格口径决定单元格价格；库存状态作为次信息显示。
5. 国家筛选既过滤 SKU，也把卡片价格行收敛到所选国家；“全部国家”时最多显示前三个国家并提示其余数量。

## 卡片信息架构

- 方形产品图占据卡片上半部，右上角显示“X 国在售”。
- 内容区依次展示品牌 / 分类 / 单位、产品名、可复制 SKU。
- 国家价格行直接纵向排列：国旗与国家、币种价格、库存状态。无需先切换国家。
- 卡片底部保留“加入计算器”和“资料”两个动作。
- 点击国家价格区打开跨国价格详情，展示每个国家的分销成本、直营成本、销售价、库存和国家 SKU；资料按钮继续打开现有完整资料弹窗。

## 权限与数据规则

- 价格口径选项只显示当前用户拥有权限的类型。
- 无任何价格权限时使用原有申请账号入口，不泄露金额。
- 国家价格详情同样遵守权限，只渲染获准列。
- 组合计算器仍加入具体国家版本，避免不同国家币种或成本混用。
- 产品分组继续以基础 `sku` 为主键，`skuNo` 和记录 ID 仅作回退。

## 视觉与动效

- 产品库使用 `Noto Sans SC / PingFang SC / Microsoft YaHei` 字体栈，SKU 与价格使用等宽字体。
- 页面背景、边框和卡片颜色保持参考模板的低对比冷灰体系，橙色仅用于同步与风险提示。
- 页面入场为 550ms、区块 reveal 为 700ms；卡片 hover 仅增加阴影，图片在 300ms 内放大至 1.05，不做整体上跳。
- 吸顶工具栏使用轻微半透明和模糊，滚动时仍保持筛选上下文。
- 尊重 `prefers-reduced-motion`，关闭非必要动画。

## 验收标准

- 真实数据仍显示 154 个基础 SKU、233 个国家版本。
- 多国 SKU 的卡片无需切换即可看到多个国家价格。
- 分销、直营、销售价格口径可切换且严格受权限控制。
- 卡片/价格矩阵、国家筛选、搜索、品牌、资料、库存、组合计算均可用。
- 1440px、390px 均无横向页面溢出；价格矩阵在小屏内部横向滚动。
- 构建、相关自动化测试通过，浏览器控制台无错误。
