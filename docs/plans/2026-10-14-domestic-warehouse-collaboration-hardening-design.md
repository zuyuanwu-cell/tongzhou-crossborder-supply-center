# 国内仓协同生产加固设计

## 目标

在不改变现有仓库授权、不修改历史工单和真实库存的前提下，优先降低国内仓协同的误操作、逾期失控和服务不稳定风险。

## 设计

- 中台任务列表增加逾期识别、逾期优先排序和人工催办。催办写入只追加时间线并生成伙伴站内通知，15 分钟内禁止重复催办。
- 新建任务必须设置截止时间；标题允许系统按“仓库 + 任务类型 + 日期”自动生成，减少人工填写。
- 手工发布只保留入库、出库、备货和异常任务。调拨收货必须来自真实调拨单，盘点差异必须走伙伴库存页的高风险审批，避免出现没有主账单据的任务。
- 伙伴确认入库或出库时，实际数量默认留空，不再自动复制计划数量；只有逐行填写有效正数后才能回传。
- 库存页把“同步时间”改为“源账变更时间”，避免把数据未变化误解为同步停止。
- 协作命令完成或驳回时同步关闭对应 integration outbox 记录，并通过一次性迁移修复历史积压。
- 经营分析物化缓存改为流式压缩写入，避免一次性 `JSON.stringify + Buffer + gzipSync` 造成数倍内存峰值和主进程崩溃。

## 验收

- 逾期任务可见、可催办，重复催办会被限流。
- 伙伴端实际数量未填写时不能提交。
- 协作 outbox 与命令终态一致。
- 物化缓存可被正常解压解析，且不再构造完整 JSON Buffer。
- 协同、国内库存、仓库工作单、构建测试全部通过。
