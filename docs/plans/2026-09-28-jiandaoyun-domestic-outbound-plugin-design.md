# 简道云国内仓出库插件设计

## 目标

在现有“简道云 → 同舟国内仓入库”链路旁新增独立的出库插件。简道云流程按产品明细逐行调用插件，中台负责定位启用仓库和现有库存、校验数量、扣减库存、记录批次分配与出库流水，并把中台出库单号返回简道云。

## 推荐方案

采用独立接口与独立令牌：`POST /api/integrations/jiandaoyun/domestic-inventory/outbound`。它与入库插件共享国内仓库存服务，但使用专用环境变量 `JIANYUN_DOMESTIC_INVENTORY_OUTBOUND_PLUGIN_TOKEN`，避免入库插件令牌具备出库能力。

插件必填仓库、简道云数据 ID、SKU 和出库数量。产品名称、图片、规格和单位优先从指定仓库的现有库存自动补齐，减少简道云表单映射工作；也允许表单传入名称作为异常兜底。可选传入批次号或条码，指定后只允许从匹配批次扣减；不指定时沿用中台先进先出规则。

## 数据流与幂等

1. 插件使用 Bearer Token 调用中台。
2. 中台精确匹配启用的国内仓和 SKU，校验可用库存及可选批次库存。
3. `dryRun=true` 时只返回校验结果，不写库存。
4. 正式调用在一个数据库事务中写出库单、扣余额、扣批次并写批次分配。
5. 幂等键由来源类型、简道云记录 ID、子表行 ID/SKU、出库批次、仓库和 SKU 生成。简道云重试不会重复扣库。
6. 返回出库单号、出库前后数量、仓库和 SKU；失败返回可识别错误码与中文提示。

## 验收范围

- 正常出库、预校验、重复触发、库存不足、仓库/SKU 不存在。
- 指定批次出库及指定批次库存不足。
- 多产品逐行调用时，每行使用不同 `sourceLineId`。
- Node.js 16 可加载服务器模块并通过构建。
- 接口不开放仓库管理、入库、调整或其他中台能力。
