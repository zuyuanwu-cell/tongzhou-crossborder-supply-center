# 店铺日报设计

## 目标

把运营每天手填的「店铺数据表」（支付金额、展示、访客、订单、加购、测评、推广费、产品成本、操作费、利润预估）搬进「运营分析 → 经营贡献 → 店铺日报」，一行代表一个店铺一天。汇率、费率和利润公式由中台统一计算，运营只录入原始数据。

## 现有运营表的问题（2026-11 评审）

- 汇率三套并存且混用：表头写 2650 / 2400 / 2200，公式实际用 2650、2400、2300；利润公式中每单费用除以 2300，金额却除以 2650。
- 部分行公式方向错误（×2650 而非 ÷2650），部分行沿用马来西亚的 ×1.65 / ×1.08。
- 两套利润公式（标准 / 叠乘）并存，店铺之间不可比。
- 汇总行跨表引用，导致店铺汇总的访客、订单、加购错误。
- 运营手工覆盖「真实成交」等公式单元格。
- 每人一个分页、每天预留占位行，无法汇总 30+ 店铺。

## 数据来源

| 字段 | 来源 | 优先级 |
|---|---|---|
| 支付金额、订单数 | 导入 / 紫鸟采集（平台口径） | 有导入值时使用；否则用经营贡献订单事实兜底，并标记「用中台订单」 |
| 展示数、访客数、加购人数 | 导入 / 紫鸟采集 | — |
| 站内、站外推广费 | 导入 / 紫鸟采集（本币，不含税） | 按费率规则加税后换算人民币 |
| 测评金额、实际收款、测评数量 | 测评订单登记 → 导入表测评列 | 某店某天有登记时以登记为准；登记金额留空时取中台同订单号金额 |
| 产品成本 | 导入值 → 经营贡献国家直营成本 | 规则可关闭中台兜底 |
| 操作费 | 导入值 → 经营贡献打包费 | 规则可关闭中台兜底（叠乘公式默认关闭，避免与每单费用重复） |

导入与采集按字段合并写入：空单元格不覆盖已有值，每个字段记录最后写入来源（`import` / `ziniao` 等）。

## 费率规则

规则保存在 `.cache/shop-daily-report.sqlite` 的 `shop_daily_meta.feeRules`，按 店铺 > 平台+国家 > 国家 > 全局默认 匹配，必须保留一条全局默认。

- 标准公式：`真实成交 × (1 − 佣金率) − 真实单量 × 每单费用 − 推广费 − 测评成本 − 产品成本 − 操作费`
- 叠乘公式：`((真实成交 × 净收比例 − 推广费) × 系数1) × 系数2 − 测评成本 − 真实单量 × 每单费用 − 产品成本 − 真实成交 × 额外扣点 − 操作费`
- `测评成本 = (测评金额 − 实际收款) + 测评数量 × 测评单位成本`
- `推广费(人民币) = 推广费(本币) × (1 + 推广税率) ÷ 汇率`
- 汇率：规则配置了固定汇率（1 人民币 = N 本币）时使用固定值，否则使用经营汇率的每日自动汇率。
- 「平台扣费」= 真实成交 − 推广费 − 测评成本 − 产品成本 − 操作费 − 利润，用于解释公式扣掉的佣金、每单费用和系数。

汇总行的 ROI、点击率、加购率、转化率、客单价、利润率均由合计重新计算，不对每日比率求和。

## 接口

| 方法 | 路径 | 权限 |
|---|---|---|
| GET | `/api/shop-daily-report?dateFrom&dateTo&shopKey&projectGroup&country&platform` | 经营贡献分析 + 经营销售金额；成本列需经营成本，利润列需经营预估利润 |
| POST | `/api/shop-daily-report/import` `{ content, dryRun, defaultYear, defaultPlatform }` | 同上 |
| POST | `/api/shop-daily-report/ingest` `{ source, rows }`，请求头 `X-Ingest-Token` | 服务器 `SHOP_METRICS_INGEST_TOKEN`（≥24 位） |
| DELETE | `/api/shop-daily-report/metrics?shopKey&date` | 同导入 |
| POST / DELETE | `/api/shop-daily-report/review-orders[/:id]` | 同导入 |
| PATCH | `/api/shop-daily-report/fee-rules` | 维护经营分析规则 + 经营成本 |

采集令牌独立于 Agent API Key：Agent Key 按设计只读，采集写入只能写店铺日数据，不能访问其他业务接口。

## 导入格式

支持从 Excel 直接复制粘贴（制表符）或 CSV。识别表头：日期、店铺、国家、平台、币种、支付金额、展示数、访客数、订单数、加购人数、测评金额、实际收款金额、测评数量、站内推广费、站外推广费、产品成本、操作费。

- 兼容运营表两行表头（合并单元格的列名取第一行）。
- 带「人民币」的换算列、ROI、利润等计算列不导入。
- 合并的日期单元格向下沿用；数字占位店铺行、空行、「汇总」行跳过。
- 日期支持 Excel 序列号、`2026-06-01`、`2026/6/1`、`2026年6月1日`、`6月1日`（配合年份参数）。
- 店铺按 名称/别称 + 国家 + 平台 匹配店铺目录；同名多店时要求补充平台列；中台订单里还没有的店铺按 `国家|平台|店铺名` 建立独立店铺键并提示。
