# 同舟画布 AI 接入设计

## 目标

在供应链中心内统一提供 AI 标题/文案、AI 生图、AI 视频，以及同舟画布已发布工作流运行能力。所有能力均使用当前登录用户自行配置的同舟画布 API Key。

## 安全边界

- API Key 只提交到供应链中心服务端，不写入浏览器存储、不返回给前端、不输出到日志。
- 每个用户独立保存配置；服务端使用 AES-256-GCM 加密，密钥文件中不保留明文。
- 生产环境优先设置独立的 `AI_CREDENTIAL_ENCRYPTION_KEY`；未设置时沿用强度合格的 `AUTH_SESSION_SECRET`。
- 同舟画布地址固定为官方 `https://hb.tongzhoukuajing.com/api/v1`，前端不能改写上游地址。
- 任务只能由创建它的用户查询，其他用户无法读取任务状态和结果。
- 产品上架文案仍要求人工审核；AI 不自动补造重量、尺寸、功效、认证和平台类目。

## 调用方式

1. 用户保存 API Key，服务端同时读取可用模型、余额和已发布工作流。
2. 前端按文字、图片、视频分类展示当前密钥可用模型。
3. 生成请求由服务端附带 Bearer Key 和幂等键提交给画布。
4. 本地任务只保存状态、模型、积分和结果，不保存用户提示词、对话或工作流输入。
5. 页面约每 5 秒轮询一次任务；完成后展示文本、图片、视频或原始工作流输出。

## 工作流

画布工作流的输入契约可由创建者自由定义，因此首版使用“契约说明 + JSON 输入”的通用运行方式，同时支持将常用生图/视频工作流保存为个人默认。后续可根据确定的工作流契约，把 JSON 输入升级为自动生成的可视化表单。

## 本地数据文件

- `.cache/tongzhou-canvas-ai-users.json`：用户级加密密钥、默认模型、能力目录缓存。
- `.cache/tongzhou-canvas-ai-jobs.json`：用户级任务状态与输出，不含提示词及工作流输入。
