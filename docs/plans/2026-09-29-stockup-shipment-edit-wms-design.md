# 发运批次编辑与仓库建单设计

## 目标

- 已创建的发运批次可修改物流、预计到仓、箱唛和装箱参数。
- 已扣减国内库存后，不允许修改起运仓、目的仓、SKU 或发运数量，避免库存流水与发运单不一致。
- 俄罗斯 YunWMS 一键创建“入库单”，东南亚 SEA WMS 一键创建“备货单”。
- 外部单号、创建状态、失败原因和操作人回写发运批次，卡片上可直接追踪。

## 安全边界

- 建单外部参考号固定使用发运单号，同一发运批次只能成功创建一次。
- 调用前先将状态写为 `pushing`；明确失败可重试，网络超时等结果不确定的错误进入 `needs_manual_check`，禁止自动重试。
- 外部单据已经创建后仍允许修改内部备注、预计到仓和装箱信息，但不允许修改已发送给 WMS 的关键业务数据。
- 所有更新使用版本号做乐观锁，冲突返回 409，不静默覆盖。

## 数据与接口

- `PATCH /api/stockup/collaboration/shipments/:id`：更新允许修改的发运字段和装箱字段。
- `POST /api/stockup/collaboration/shipments/:id/wms-order`：按目的仓 WMS 类型创建入库单或备货单。
- 发运表记录 WMS 类型、建单状态、外部单号、错误、尝试次数、创建时间和操作人。

## 界面

- 发运卡片提供“编辑”按钮。
- 建单按钮按目的仓显示“创建入库单”或“创建备货单”。
- 卡片内显示创建中、已创建、失败或待人工核对状态；已创建时展示外部单号。
