# V0 参考版中台 UI 优化设计

## 目标

在不改变现有接口、权限判断和业务页面功能的前提下，吸收 V0 参考版的信息层级与动效语言，重点改善经营工作台首屏和全局导航壳层。

## 采用方向

选择“全局壳层 + 经营工作台定向升级”，不做整站组件重写：

- 顶部栏改为清晰的业务面包屑、全局搜索、语言、同步和账号区。
- 侧栏默认只展开当前业务域，降低长菜单的视觉噪声；保留用户主动展开多个业务域的能力。
- 经营工作台新增深蓝指挥舱首屏，将欢迎语、数据健康度和四个核心指标合并为一个视觉焦点。
- 待办继续保持最高业务优先级，放在指挥舱之后；同步健康度、仓库状态和经营口径继续沿用现有数据与交互。
- 卡片使用薄边框、柔和阴影、统一圆角；橙色仅用于动作和风险提示，蓝色承担结构与品牌识别。

## 动效原则

- 首屏使用一次 280–420ms 的分层进入动画。
- 导航分组使用高度和透明度过渡，不使用突然隐藏。
- 可点击卡片和按钮仅做 1–2px 位移与阴影反馈。
- 完整支持 `prefers-reduced-motion`，避免持续性装饰动画。

## 响应式

- 桌面端四列核心指标置于指挥舱底部。
- 中等宽度改为两列指标，顶部操作保持可换行。
- 移动端改为单列内容；侧栏仍使用抽屉，不改变现有操作方式。

## 验证

- TypeScript 与 Vite 生产构建通过。
- 仪表盘摘要、权限和用户角色测试通过。
- 使用独立缓存启动本地服务，检查桌面和窄屏截图、侧栏展开动画、控制台错误与关键页面导航。
