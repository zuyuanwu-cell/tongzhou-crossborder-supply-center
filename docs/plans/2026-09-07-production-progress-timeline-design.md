# 生产中心时效与跟进时间线设计

## 目标

让供应链人员无需打开单据详情，就能判断生产单从开单至今已进行多少天、是否接近或超过预计完成日期，并像查看快递轨迹一样展开查看跟进过程。

## 方案选择

采用“按生产单聚合、SKU 行作为明细”的方案。相比按 SKU 独立展示，它更符合开单与跟单的实际责任边界；相比只做静态阶段条，纵向时间线能够保留多次进度更新、退回、发货和 WMS 确认记录。

## 数据与兼容

- 正式生产执行单：以开单时间为起点，关联现有操作日志、发货记录与 WMS 确认记录，生成真实跟进事件。
- 委外加工同步单：读取记录创建时间、最后更新时间、状态、预计完成时间和跟单备注，形成来源可解释的时间线。
- 旧单缺少历史日志时仍展示开单和当前快照，并明确标注“当前状态”，不虚构历史时间。
- 已进行天数按自然日计算；预计完成日在未来时显示剩余天数，超过时显示逾期天数。

## 界面

- 生产单卡片顶部增加醒目的“已进行 X 天”时效徽标。
- 同时显示开单日期和“距预计完成 X 天 / 已逾期 X 天 / 未配置预计完成”。
- “展开跟进记录”按钮控制纵向时间线，默认收起，避免生产中心变得过长。
- 时间线节点区分完成、当前、提醒与预计四种视觉状态；每条显示时间、事件、操作人及关键数量。
- 移动端改为单列，时间线和操作按钮保持完整可读。

## 验证

- 单元测试覆盖事件关联、排序、旧单回退、WMS 关联和重复事件去重。
- TypeScript 与 Vite 生产构建通过。
- 本地页面验证生产中心的折叠、展开、长备注、无历史记录和响应式布局。
