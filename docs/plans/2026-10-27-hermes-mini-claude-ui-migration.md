# Hermes 伙伴小程序 Claude UI 迁移设计

## 目标与边界

- 以 `小程序/Hermes智能体供应商填报UI/Hermes 首页 v2.dc.html` 为视觉源。
- 保留现有原生微信小程序业务能力、API、权限、会话、语音和文件上传实现。
- 本次不上传体验版、不提交审核、不发布生产；完成本地验证后由用户确认下一步。
- 不从主仓库脏工作区构建，实施基线为干净提交 `0444038`。

## 现有项目审计

### 技术栈

- 原生微信小程序：JavaScript + WXML + WXSS + JSON。
- 不使用 npm、React、Vue、Taro 或外部 UI 组件库。
- AppID：`wxdefe3faf2c852d54`，基础库 `2.20.1`。
- 自定义组件：`components/tz-tab-bar`；其他页面主要为 Page 级组件。

### 路由

- 伙伴端：登录、Hermes 首页、Hermes 进度会话、任务列表、任务详情、库存、仓库操作、消息、个人中心。
- 管理端：移动总览、业务模块、任务、审批、组织、装柜测算等。
- 首页、登录、Hermes 会话和个人中心使用 `navigationStyle: custom`。

### 状态管理

- `App.globalData.session` 保存当前会话，并同步到 `wx` 本地存储。
- 页面使用 `Page.data/setData` 管理局部状态。
- Hermes 快捷汇报会话、候选订单、草稿、版本冲突和语音状态集中在 `pages/ai-progress`。
- 用户偏好使用本地存储；没有独立全局状态框架。

### API

- 伙伴 API 集中在 `utils/api.js`，管理 API 集中在 `utils/admin-api.js`。
- 涵盖登录、会话、工作台、任务、库存、通知、附件、生产里程碑和 Hermes 会话。
- Hermes 正式提交继续复用现有业务接口，包含任务版本和幂等键。
- UI 迁移不得修改 API 路径、权限检查、任务筛选或提交确认语义。

### CSS/WXSS

- 现有页面以 Page 级 WXSS 为主，`app.wxss` 提供卡片、字段、按钮和状态基础样式。
- Hermes 首页、登录、会话、个人中心已经有深色主题，但颜色、玻璃层次、间距、圆角和动效未完全对齐最新 Claude 原型。
- 任务、库存、消息等旧页面仍以浅色中台样式为主。

## Claude 导出项目审计

### 技术与结构

- 单文件设计文档 HTML，约 72KB。
- 依赖本地 `support.js`（约 69KB）的设计画布运行时。
- 使用非标准元素 `x-dc`、`sc-if`、`sc-for` 和 `text/x-dc` 状态脚本。
- 不是微信小程序工程，也不是可直接构建的 Web 工程。
- 包含三个明确页面：Hermes 首页 v2、登录、个人中心。
- 交互脚本只模拟登录、进度填报、异常上报、物流反馈和语音动画，不连接真实 API。

### 可直接复用

- 信息层级、页面结构、文案、卡片组合和动作优先级。
- 颜色、圆角、阴影、渐变、网格背景和动效参数。
- Hermes 对话中的识别、思考、确认、成功和继续处理状态设计。
- 登录端伙伴/中台双模式的视觉差异。

### 必须迁移而不能直接复制

- HTML/CSS 需转换为 WXML/WXSS。
- `DCLogic` 状态和事件需映射到现有 `Page` 方法。
- `backdrop-filter`、`mask-image`、CSS hover、DOM 滚动和 requestAnimationFrame 需改为小程序兼容实现或降级。
- Google Fonts 不能作为小程序远程字体依赖；正文沿用苹方/微软雅黑，数字使用系统等宽字体栈。
- 原型模拟数据必须替换为现有工作台、任务、Hermes 会话和组织授权数据。

### 素材与不可运行部分

- 唯一外部依赖为 Google Fonts 的 JetBrains Mono；生产小程序不引入。
- `uploads` 下 10 张 414×780 PNG 是业务页面参考截图，HTML 未直接引用，不作为运行素材打包。
- `.thumbnail` 是设计预览，不作为产品资源。
- `support.js` 仅供 Claude 设计文档运行，不进入小程序包。
- 原型未提供正式图标包、深色任务详情、库存、消息和仓库表单设计。

## Design Tokens

### 色彩

- 背景：`#04060D`、`#070B1A`、`#0B0F1C`、`#0B1230`。
- 主文字：`#EEF2FF`；次级文字：`rgba(214,222,255,.68)`。
- Hermes 青：`#5CE1FF`、`#8FEAFF`。
- 智能蓝：`#3B5BFF`、`#22A6FF`、`#2F4DFF`。
- 行动橙：`#FF6A2A`、`#FF7A3D`、`#FF9F5C`。
- 成功绿：`#3DDC97`、`#7FF0BE`。
- 风险红：`#FF8A96`。
- 中台绿：`#0FA884`、`#3DF0C0`。

### 字体

- 中文正文：`PingFang SC` / `Microsoft YaHei`。
- 数字与编号：系统等宽字体；不加载远程 JetBrains Mono。
- 页面标题 40–48rpx，卡片标题 27–30rpx，正文 22–26rpx，辅助信息 18–21rpx。

### 间距与形状

- 页面左右留白 28–32rpx。
- 内容节奏 12/16/20/24/32rpx。
- 卡片圆角 28–44rpx；控件圆角 20–32rpx；胶囊为 999rpx。
- 卡片边框 `rgba(255,255,255,.12–.16)`。

### 阴影与渐变

- 玻璃卡片：深色半透明渐变 + 内高光 + `0 20rpx 60rpx` 深色阴影。
- 主按钮：蓝色或橙色 135° 渐变；伙伴动作优先使用橙色。
- Hermes 光环：青—蓝—紫—橙锥形渐变的兼容近似。

### 动效

- 入场：上移 14px、淡入、500–600ms、`cubic-bezier(.2,.8,.2,1)`。
- 思考：光环 1.2s 旋转 + 三点 1s 跳动。
- 呼吸：4s 循环。
- 提交成功：400–500ms 回弹。
- 语音：900ms 波形循环。
- 尊重性能：列表长页不对每个卡片持续动画，低端机保留静态降级。

## 页面映射

| Claude 页面/组件 | 现有页面 | 迁移方式 |
|---|---|---|
| Hermes 首页 v2 | `pages/index` | 保留数据装配与跳转，重构 WXML/WXSS |
| 对话、进度草稿、异常卡片 | `pages/ai-progress` | 保留真实会话状态机，迁移卡片和动效 |
| 登录 | `pages/login` | 保留双域登录和错误处理，迁移布局与主题 |
| 个人中心 | `pages/profile` | 保留权限、偏好和退出逻辑，迁移视觉 |
| 玻璃底部栏 | `components/tz-tab-bar` | 统一伙伴端视觉，管理端保持兼容 |
| 今日任务 | `pages/tasks` | 保留筛选和列表结构，统一为 Hermes 深色玻璃主题 |
| 订单详情/表单 | `pages/task-detail` | 不重写复杂表单，共享 Tokens、深色表面和顶部外壳 |
| 消息/库存/仓库操作 | 对应现有页面 | 保留业务结构，迁移背景、卡片、控件和底栏主题 |

## 风险与保护

- 不能把原型假数据写入正式页面。
- 不能改变组织隔离、可见任务过滤、权限或会话域。
- 不能在 UI 迁移中绕过确认直接提交。
- 不能依赖 Google Fonts、HTML DOM、hover 或 Web-only 滤镜。
- 必须保留手工表单兜底、版本冲突处理、ASR/Hermes 故障降级。
- 必须检查滚动区、键盘顶起、安全区、刘海屏和小屏布局。
- 图片和附件预览仍走现有安全 URL 与微信 API。
- 发布前必须从干净提交上传；本轮按用户要求不发布。

## 实施策略

1. 建立共享 Hermes 主题与原型等价动效。
2. 对齐登录、首页、会话、个人中心和底部导航，并为任务、消息、库存、仓库作业和任务详情补齐同一视觉语言。
3. 保持 API、权限和提交路径不变；仅修复首页中文快捷话术在路由中未解码的问题。
4. 运行小程序合同测试、静态引用检查和微信开发者工具构建。
5. 生成迁移对照和测试说明，等待用户确认后再上传体验版。

## 本轮实施结果

- 首页已按 Claude V2 重组为 Hermes 状态头、动态光环、今日任务玻璃卡、快捷话术和悬浮输入区。
- Hermes 会话、登录和个人中心通过共享高优先级 Tokens 对齐原型，同时保留真实会话、语音、组织权限和退出逻辑。
- 伙伴端底栏统一为安全区内的悬浮玻璃导航；任务、消息、库存、仓库作业和任务详情完成同主题迁移，避免主页面深色、业务页突然切回浅色。
- 未复制 Claude 的模拟状态脚本，也未打包 `support.js`、截图、缩略图和 Google Fonts。
- 修复首页快捷话术进入 Hermes 后显示 `%E6...` URL 编码的问题。
