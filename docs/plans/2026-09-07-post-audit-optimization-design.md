# 同舟供应链审查后优化设计

## 目标

在不部署、不改写线上数据的前提下，修复本次用户视角审查发现的数据可信度、旧主题残留、误导状态、产品列表性能和中等宽度适配问题。

## 已确认的实现方向

1. 仓库订单同步采用“按仓原子发布”：本轮成功且数据完整才替换该仓缓存；失败、超时、跳过或分页不完整时继续使用该仓最近一次成功数据，并明确标记沿用缓存。
2. 库存风险与经营分析区分“正式、暂估、沿用历史、不可用”四种状态；没有可用订单时不再用 `0` 表示风险结论。
3. 订单分析默认最近 90 天，提供 7/30/90 天快捷范围，避免页面说明与实际查询不一致。
4. 保持现有橙蓝白运营工作台方向，在最后加载的主题层统一覆盖生产、经营贡献、弹窗、表格和工作流中的旧深色变量，确保正文、标签和辅助文字清晰。
5. 产品中心首批只渲染有限数量的产品并逐批加载，图片使用延迟解码；品牌筛选按大小写归一并过滤占位值。
6. 产品详情补齐 Escape 关闭、焦点锁定和焦点返回；中等宽度下压缩顶部操作区、筛选和网格密度，避免换行及裁切。

## 验收标准

- 任一仓库同步失败不会把该仓上一轮订单清空。
- 数据不完整时页面有清晰说明，不能被误读为完整的零风险或完整利润。
- 订单分析首次进入显示最近 90 天。
- 生产管理、经营贡献及详情弹窗不再出现深底深字。
- 390、768、960、1180、1440 宽度无关键操作遮挡或横向溢出。
- 产品中心不会一次渲染全部产品；详情弹窗可完整键盘操作。
- 构建与核心业务测试全部通过，本地页面无新增控制台错误。
