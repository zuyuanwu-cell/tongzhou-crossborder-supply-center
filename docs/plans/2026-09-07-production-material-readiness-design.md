# 生产中心物料到齐设计

## 目标

在生产中心按生产单展示采购与入库进度，让用户能直接判断包材是否到齐，同时对供应商名称和关联标识做服务端脱敏。

本阶段只读取简道云数据并计算展示结果，不修改采购订单、采购入库单或委外加工单。

## 数据来源与关联

- 委外加工单提供生产单号、加工方、生产状态和生产明细。
- 采购订单通过委外加工单号关联生产单，采购明细提供物料 SKU、分类、供应商和应到数量。
- 采购入库单通过采购订单号关联采购单，入库明细提供物料 SKU、分类、实到数量和入库时间。
- 查询只覆盖当前生产中的单据，并按 20 个单号分批读取，避免扫描整个采购与入库表。

## 判定规则

1. 内包辅材、外包辅材及名称明确属于包材的物料必须全部到齐。
2. 内料默认不参与物料到齐判断。
3. 当内料供应商与委外加工方不是同一主体时，该内料作为例外物料，必须到齐。
4. 同一采购单、同一物料的多张入库单累计计算实到数量。
5. 已取消、作废、驳回或终止的采购订单不参与计算。
6. 没有可识别包材明细的生产单显示“数据待核查”，不得自动判定到齐。

## 展示状态

- `物料到齐`：所有必需包材及异厂内料均已达到应到数量。
- `部分到齐`：至少一项必需物料已有入库，但仍有未到齐项。
- `待到货`：已识别必需物料，但尚无有效入库数量。
- `数据待核查`：未识别到包材，或数据不足以可靠判断。

生产列表显示状态、完成项数和进度；展开跟进轨迹后显示物料节点、累计数量以及脱敏后的供应商代号。

## 隐私与安全

- 供应商名称与供应商 ID 在服务端转换为稳定匿名代号，例如“供应商 A7C2”。
- 浏览器接口不返回采购记录原文、供应商原名、供应商 ID 或委外加工单原始数据。
- 跟单备注、交付状态等自由文本中出现的已知供应商全称或简称也会替换为对应匿名代号。
- 同一供应商在不同记录中保持相同代号，以便用户识别是否为同一主体。
- 当前逻辑只读，不调用任何简道云更新接口。

## 容错与缓存

- 物料计算结果独立缓存。
- 采购或入库读取失败时保留上一份可用结果，并在接口中提供同步警告。
- 即使首次物料同步失败，生产中心仍可展示基础生产数据，物料状态退回“数据待核查”。

## 验收标准

- 同厂内料不影响包材到齐判断。
- 异厂内料未到齐时，生产单不能显示“物料到齐”。
- 多次入库可正确累计。
- 无包材的生产单显示“数据待核查”。
- 前端响应中不存在供应商原名或原始简道云记录。
- 同舟供应链与国内定制两个生产选项卡均能显示物料进度，默认仍为同舟供应链。
