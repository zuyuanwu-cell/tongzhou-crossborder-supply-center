# 智能装柜二期设计：方案生命周期、自动选柜与沉浸式控制台

## 目标

- 作废方案默认退出当前列表，可归档、恢复，并在明确确认后永久删除。
- 自由模拟时支持“智能匹配柜型”，按货物箱规、总体积、载重与实际排布结果选择更合适的柜型。
- 修复箱规与尺寸输入重叠，窄屏时保持字段可辨识并允许横向滚动。
- 3D 控制台支持沉浸式全屏；每个 SKU 使用稳定且高辨识度的颜色，并展示颜色图例。
- 支持下载多页可视化 PDF 装柜指导报告，供仓库按阶段执行和签核。

## 方案生命周期

为 `container_loading_plans` 增加只向前兼容的生命周期字段：

- `lifecycle_status`: `active` / `archived`，默认 `active`。
- `archived_at`、`archived_by`: 记录归档时间及人员。

当前方案列表默认只查询 `active`。只有已经作废的方案可以归档或永久删除；永久删除需要二次确认，并同时删除该方案的版本记录。归档和恢复都进行乐观锁版本校验并追加版本事件，避免多人同时操作造成静默覆盖。

## 智能柜型选择

系统依次评估 20GP、40GP、40HQ、45HQ：

1. 对每个柜型生成最大装载、重量均衡、SKU 完整三套候选方案。
2. 优先选择能够完整装下全部货物的最小柜型，减少空间浪费。
3. 若没有单柜能全部装下，则按已装箱数、未装箱数、体积利用率、重量余量和重心均衡综合选择。
4. 保存推荐理由与柜型对比结果，供用户查看；用户仍可切回指定柜型重新计算。

智能模式只改变计算与推荐，不改变装柜确认、版本留痕和来源发运单校验规则。

## 界面与交互

- 方案侧栏增加“当前方案 / 已归档”切换。作废方案提供归档和删除；已归档方案提供恢复和删除。
- 柜型选择默认提供“智能匹配”，计算后在方案标题区展示推荐柜型、推荐原因及其他柜型对比。
- 自由模拟表格为尺寸字段预留独立网格，输入框使用 `min-width: 0` 和统一 `border-box`；小窗口以横向滚动承载完整表格。
- 3D 区域增加全屏/退出全屏按钮，优先使用浏览器 Fullscreen API，失败时回退到应用内固定定位全屏。
- SKU 使用稳定哈希映射到高对比度调色板；货物清单、3D 箱体与图例共用同一颜色函数。

## 仓库装柜指导报告

PDF 由浏览器本地生成并直接下载，不上传额外数据，也不依赖生产服务器安装新的 PDF 组件。报告包含方案状态与版本、柜型参数、装载指标、带 SKU 颜色的俯视图、四阶段装柜顺序、SKU 箱规与实装明细、现场核对表和风险提醒。报告中的颜色映射和 3D 控制台保持一致；草稿、作废方案会明确标注状态，避免被仓库误当成已确认指令。

## 安全与验收

- 列表、详情、归档、恢复和删除继续复用现有数据范围校验。
- 所有状态变更携带 `expectedVersion`；冲突返回 409。
- 数据库迁移只新增列并提高 schema 版本，不重建、不清空现有表。
- 增加自动选柜、归档默认隐藏、恢复及删除约束测试；完成 Node 16 构建与真实浏览器布局回归。
