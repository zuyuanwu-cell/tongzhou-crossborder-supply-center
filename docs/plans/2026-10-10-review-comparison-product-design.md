# 复盘中心环比与产品复盘设计

## 权限边界

- 业务链路仅管理员可见、可查询和可同步。
- 菜单、权限计算、Agent 页面索引和业务链路 API 同时实施硬限制，普通内部账号即使保留历史授权也不能访问。

## 环比口径

- 当前周期为用户选择的起止日期（包含首尾）。
- 对比周期为当前周期之前、天数完全相同且连续的上一周期。
- 数量和金额展示增减值及增减率；上期为 0、本期大于 0 时显示“新增”，避免伪造无穷百分比。
- 用户行为趋势同时绘制本期和上期对齐曲线；排行、任务状态、仓库表现和售后归因均携带上期值。

## 产品口径

- 来源为 WMS 已出库订单，以实际出库时间优先，缺失时回退订单日期或创建时间。
- 对比本期与等长上一周期的出库件数、活跃 SKU、订单数和头部集中度。
- 头部：本期出库量前列；增长：较上期增量最大；下滑：较上期减少最多；尾部：本期低出库以及上期有量但本期为零。
- 只返回聚合结果，不向页面暴露订单原始载荷。
