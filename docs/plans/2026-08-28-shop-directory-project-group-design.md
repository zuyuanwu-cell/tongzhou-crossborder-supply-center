# 店铺档案与主项目组设计

## 目标

将 WMS 已出库订单中的店铺身份、妙手店铺别称和中台项目组配置统一起来。一个店铺只归属一个主项目组；项目组配置同时用于经营贡献和订单分析。

## 数据原则

- 业绩事实继续以 WMS 已出库订单为准，妙手不作为销售额来源。
- WMS 原始店铺名保留在事实数据中，不因别称或项目组调整而重写历史订单。
- 店铺键由国家、平台和 WMS 原始店铺名归一化生成，避免同名跨国家店铺串联。
- 妙手店铺仅在平台、站点和店铺名唯一匹配时自动关联；多候选时保持未匹配，避免误关联。
- 展示名优先级为：人工别称、妙手 `shopNick`、妙手平台店铺名、WMS 原始店铺名。
- 主项目组优先使用人工配置；尚未配置时兼容现有 WMS 推断结果。

## 操作与权限

经营贡献页面增加“店铺归属”页签。管理员可勾选多个店铺并批量设置一个主项目组；接口再次校验管理权限和店铺键存在性。普通用户只能查看自己数据范围内的店铺与项目组。

## 数据质量

页面明确区分销量事实、销售额覆盖范围和利润覆盖范围。销售额或成本覆盖不足时仍展示覆盖范围内金额，但必须同时显示覆盖率警告，避免将局部利润解释为整体利润。

## 验证

- 单元测试覆盖跨国家同名店铺、妙手别称匹配、人工别称优先、歧义匹配失败和主项目组覆盖。
- API 冒烟测试覆盖未授权访问、批量项目组更新和分析筛选。
- 构建后在本地页面验证筛选、批量选择和保存后的数据刷新。
