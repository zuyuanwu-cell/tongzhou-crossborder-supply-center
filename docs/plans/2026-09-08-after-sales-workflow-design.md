# 售后协同工作流设计

## 目标

在同舟中台内建立一条可追溯的售后闭环：运营用平台后台订单号同步妙手原单，选择售后原因与处理方式，补充证据、备注和补发明细；系统自动判断责任、冻结成本快照并计算仓库承担金额；仓库账号在独立工作台接单、复制收件与补发信息、上传面单并完结。

## 方案选择

采用“单一售后工单 + 双角色工作台 + 事件时间线”。运营端和仓库端读写同一张工单，不复制两套数据；每一次提交、接单、上传面单、发出和完结都追加不可变事件。相比把运营记录和仓库记录分开，这种结构能避免状态不同步，也便于后续对账和统计。

本期不直接修改妙手订单、WMS 订单或财务账，只读取妙手原单并生成中台责任单。外部系统写入作为后续可控扩展。

## 权限

- `after_sales_report`：运营填报、查看、补充售后资料。
- `after_sales_warehouse`：仓库处理、上传面单、完结工单。
- 管理员默认拥有两项权限；直营内部账号默认拥有运营填报权限。仓库账号使用直营角色并由管理员仅开放仓库处理权限。
- 客户姓名、电话和地址不出现在列表，只在工单详情中按权限展示，并提供主动复制按钮。

## 工单状态

`待仓库接单 → 处理中 → 待补发 → 已发出 → 已完结`

- 不需要补发的工单可从“处理中”直接完结。
- 需要补发的工单必须维护补发商品并上传面单后才能标记已发出。
- 管理员可作废异常工单；任何责任或金额人工调整必须填写原因并写入时间线。

## 自动责任规则

| 一级原因 | 默认责任 | 默认金额规则 |
| --- | --- | --- |
| 仓库错发 | 仓库 | 受影响错品成本 + 补发打包费减免 |
| 仓库漏发少发 | 仓库 | 少发商品成本 + 补发打包费减免 |
| 产品质量问题 | 产品/供应链 | 默认不计仓库承担；可人工转责 |
| 快递丢失 | 物流 | 默认不计仓库承担；仓库可协助举证 |
| 运输破损 | 物流 | 默认不计仓库承担；若包装不当可人工转责 |
| SKU匹配错误 | 运营/系统 | 默认不计仓库承担；可人工转责 |

二级处理会进一步影响金额：

- “补发且留错品”：需要补发；仓库责任时计受影响商品成本和一次补发打包费减免。
- “仓库发错货，客户差评不退货”：仓库责任；计错品成本，可填额外赔付。
- “客户补差价留错品”：仓库责任；错品成本减去客户补差价，最低为 0。
- “客户退全款且退货”：仓库责任时计原单打包费减免和确认破损/不可二次销售商品成本；未破损退回商品默认不计产品损失。

系统保留“额外调整”和“客户补回”字段，应对补发运费、平台罚款、部分退款、退货可二次销售、重复售后等未穷尽情况。所有调整必须备注。

## 成本口径

1. 优先取订单国家对应产品库的直营成本。
2. 产品库没有时，取经营分析中有效的手工补充成本。
3. 外币成本按订单日期最近且不晚于该日期的汇率折算人民币。
4. 仍缺失时必须由运营手工录入单价，系统标记“人工成本”。
5. 打包费复用经营贡献模块当前启用的国家计费规则。
6. 创建工单时冻结 SKU、数量、单价、汇率来源和打包费快照，之后产品库或汇率变化不回写旧工单。

仓库承担金额：

`受影响产品成本 + 打包费减免 + 额外承担 - 客户补回`

结果不低于 0，所有金额保留两位小数。

## 原单同步

- 只允许平台后台订单号精确匹配。
- 先查本地妙手订单缓存；若本地没有或缺少明细，再按平台与店铺分批实时查询妙手。
- 同一订单号命中多个店铺时不自动选择，返回冲突提示，避免串单。
- 同步原单 SKU、数量、店铺别名、国家、平台、下单时间；收件信息按妙手返回字段尽力提取。若开放接口未返回隐私字段，允许运营手工补齐，不伪造数据。
- 允许同一原订单存在多次售后，但提交前提示已有工单，防止重复计责。

## 附件与审计

- 运营证据和仓库面单分别上传，单文件不超过 8MB，支持 PNG、JPG、WEBP、GIF 和 PDF。
- 附件接口必须登录并具有对应售后权限，不能使用公开静态链接。
- 工单时间线记录操作者、动作、备注与时间；敏感客户信息不写入操作日志详情。

## 页面结构

- 顶部为售后概览：待接单、待补发、处理中、仓库待承担金额。
- “运营填报”采用三步结构：同步原单 → 原因与证据 → 补发与结算。
- “仓库处理”提供状态筛选、关键词检索和工单详情抽屉；详情内可复制客户信息/补发清单、上传面单、流转状态和完结。
- 首屏优先读本地工单与本地订单缓存，只有点击“同步原单”时才访问妙手，避免进入页面长时间缓冲。

## 验收标准

- 精确订单号可同步 SKU、产品名和数量；歧义/未命中有明确提示。
- 六个一级原因、四个二级处理均能保存，自动责任结果可解释。
- 缺成本不可提交，补录后金额实时重算。
- 需要补发时必须选择商品和数量。
- 仓库账号可看待处理单、复制必要信息、上传面单并完结；无运营权限时看不到填报入口。
- 列表不泄露客户完整联系方式；刷新页面后工单与时间线仍存在。
