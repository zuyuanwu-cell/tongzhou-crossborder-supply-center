# 备货预警企业微信长图设计

## 目标

在库存和订单同步完成后，自动把备货预警生成一张适合手机查看的长图，先推送图片，再推送一条带中台详情链接的文字消息。通知使用现有企业微信机器人和“备货建议”场景配置，不新增另一套收件人配置。

## 信息结构

- 顶部：报告日期、需要备货 SKU 数、紧急 SKU 数、净建议备货总量、最近预计断货时间。
- 产品卡片：产品名称与 SKU、国家/主要仓库、风险状态、近 30 日销售趋势、昨日出库、昨日有效订单预占、可售库存、在途、委外在产、建议备货、净建议备货、预计断货日期。
- 底部：数据更新时间、口径提示，以及未在长图展开的剩余 SKU 数。

## 自动发送规则

1. 复用库存/订单同步完成后的备货计算结果。
2. 每个自然日首次得到有效预警时发送完整长图；同一天只有新增预警 SKU 时再次发送，普通数量波动不重复打扰。
3. 长图默认展示按断货紧迫度排序的前 20 个 SKU，剩余项目通过中台链接查看。
4. 图片生成或发送失败时自动降级为原有文字预警，避免通知链路中断。
5. 长图不包含成本、供应商、客户或店铺等敏感信息；详情链接仍受中台登录与权限控制。

## 技术方案

- 服务端根据备货数据生成 SVG，再用 `@resvg/resvg-js` 渲染 PNG；该依赖支持 Node.js 10+，兼容现有旧服务器运行环境。
- 使用企业微信机器人 `image` 消息发送 PNG（base64 + MD5），随后发送 markdown 详情链接。
- 图片超过企业微信 2MB 限制时自动缩小渲染宽度，仍超限则触发文字降级。
- 提供管理员预览接口，便于上线后核对真实数据版式而不触发群通知。

## 视觉方向

沿用中台深蓝、橙色和浅灰蓝配色。长图宽 1080px，采用高对比数字、短标签和趋势折线，减少说明文字，确保手机端点开后可以快速扫读。
