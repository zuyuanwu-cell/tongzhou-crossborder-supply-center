# 同舟供应链独立登录页设计

## 目标

将现有的顶部登录浮层升级为全屏独立登录体验，在不改变认证接口、账号体系和权限逻辑的前提下，让登录成为品牌体验的一部分。

## 视觉方向

- 主题：我们是同一艘船上的人。
- 左侧为深海蓝色的数字航行场景，使用 SVG 与 CSS 绘制帆船、海浪、航线、星光和数据网格。
- 右侧为暖白登录区，以橙色作为行动色、蓝色作为可信与系统色。
- 不加载外部图片或字体，保证本地环境下稳定、快速。

## 交互结构

- 点击任意“登录”入口后打开全屏登录页。
- 支持账号密码、内部访问码和首次初始化管理员三种既有模式。
- 页面提供关闭按钮与返回产品库入口；按 Escape 可关闭。
- 登录成功后关闭登录页，并延续原有的目标页面跳转逻辑。
- 请求中禁用提交按钮并显示明确状态，错误信息保留在表单内。

## 响应式与可访问性

- 桌面端左右分栏；窄屏改为纵向，上方保留精简航行场景、下方展示登录表单。
- 使用语义化表单标签、可见焦点、`aria-modal` 和状态播报。
- 尊重 `prefers-reduced-motion`，关闭船体、海浪与星光动画。

## 验收

- 账号、访问码、首次初始化逻辑保持可用。
- 390、768、1440 宽度无横向溢出，登录区可完整操作。
- TypeScript 构建、权限测试通过，浏览器控制台无新增错误。
