# ADR-0003：管理员分配密码后直接登录

- 状态：已接受
- 日期：2026-09-28
- 替代：ADR-0002 中关于首次登录强制改密的决定
- 补充：登录凭据已由 ADR-0004 简化为账号和密码

## 决策

内部管理员或组织管理员创建伙伴账号时直接分配登录密码。用户收到伙伴网址、账号和密码后即可进入工作区，不再显示首次改密页面，也不因 `must_change_password` 阻止业务接口。组织代码不再属于伙伴登录凭据，详见 ADR-0004。

用户仍可在“账号安全”中自愿修改密码或补充找回邮箱。密码继续使用 Argon2id 哈希保存，开户明文只在当前管理员页面内存中临时显示。

## 兼容处理

- 新建账号的 `must_change_password` 始终写入 `false`。
- 增量迁移将历史账号的该标志统一置为 `false`。
- 保留数据库字段，避免破坏旧数据结构和回滚能力。
- 登录限流、失败锁定、会话撤销、CSRF、组织权限、RLS 与审计机制保持不变。
