# ADR-0002：伙伴门户采用账号密码与首次改密

- 状态：已被 ADR-0003 部分替代
- 日期：2026-09-28
- 替代：ADR-0001 中关于强制 TOTP 的身份决策

## 决策

伙伴门户不再提供或强制使用 TOTP 验证器。内部管理员或组织管理员直接分配账号和密码；邮箱仍为可选资料，可由成员登录后补充并用于密码找回。（首次改密要求已由 ADR-0003 替代，组织代码登录要求已由 ADR-0004 替代。）

取消验证器不改变以下控制：

- 密码使用 Argon2id 哈希，明文只在开户页面内存中临时显示，不写入数据库或日志。
- 登录限流、连续失败锁定、服务端会话、CSRF、组织状态与成员停用继续生效。
- PostgreSQL RLS 与 API 组织权限双重隔离继续生效。
- 报价、库存动作和成员变更继续校验岗位权限、对象归属、版本、幂等键与审批规则，并写入审计记录。
- 生产迁移只将历史 `mfa_required` 标志设为 `false`，保留旧列与已存在的密文数据，不执行破坏性删除。

## 开户交接

开户成功后，页面提供一次性凭据卡和“一键复制开户文案”，内容包括伙伴网址、组织名称、登录账号和登录密码。凭据卡关闭或页面刷新后不再显示明文密码，服务端也不提供找回明文密码的接口。
