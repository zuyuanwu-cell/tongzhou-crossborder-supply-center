# 同舟智数 使用说明

同舟智数是一个 Windows 桌面程序：它通过紫鸟 CLI 打开紫鸟里的店铺浏览器，在已经登录的 Shopee 卖家中心里读取每天的访客、曝光、加购、销售额、订单和广告花费，然后写入同舟供应链中台的「店铺日报」。运营不用再手工抄数。

- 只读取数据，不会改动店铺里的任何设置；
- 不保存、不导出 Shopee 登录信息，数据请求都在紫鸟店铺窗口内完成；
- 后续要加 TikTok Shop 等平台时，只需要增加平台适配，界面与流程不变。

## 一、准备（只做一次）

1. **服务器开启采集令牌**（管理员做）：在中台服务器的环境变量里设置 `SHOP_METRICS_INGEST_TOKEN=<一串至少 24 位的随机字符>`，重启中台。这个令牌只能写入店铺日报，不能登录中台。
2. **紫鸟客户端**：用来采集的这台电脑上安装紫鸟浏览器并登录（建议使用固定的一台办公电脑）。每个要采集的店铺，先在紫鸟里手动打开一次，确认 Shopee 卖家中心是登录状态。
3. **解压运行**：把 `同舟智数-x.x.x-win-x64.zip` 解压到固定位置（例如 `D:\同舟智数`），双击 `同舟智数.exe`。

## 二、首次设置

打开后按「总览」页上的四步走：

1. **设置 → 同舟供应链中台**：填写中台地址（`https://gyl.tongzhoukuajing.com`）和采集令牌，点「测试连接」。
2. **设置 → 紫鸟 CLI**：点「检查紫鸟环境」。如果提示没有找到 CLI，点「一键安装紫鸟 CLI」（也可以用 `npm install -g @ziniao-open/cli` 安装后再检查）。如果 doctor 提示未配置 API Key，在命令行运行一次 `ziniao-cli config init` 按提示完成。
3. **采集模板 → 新建模板（校准）**：
   - 选一个已登录的 Shopee 店铺，卖家中心选「中国卖家中心（CNSC）」或对应的本地站点；
   - 点「打开并抓取接口」，紫鸟会打开该店铺的「商业分析」页面；
   - 在弹出的紫鸟窗口里把日期切到**昨天**，再打开**广告**页面看一下广告花费，然后回到同舟智数点「我已在窗口里操作，再抓一次」；
   - 勾选数据接口（默认已勾好），填写 Shopee 店铺 ID（CNSC 多站点时需要，见卖家中心地址栏 `cnsc_shop_id=` 后的数字），点「生成模板」；
   - 检查「字段映射」：程序已自动推荐，点「试采这一天」，把试采值和卖家中心页面上的数字逐个对照。广告花费如果大了 10 万倍，把「除以」填 `100000`；
   - 核对无误后「保存模板」。同类卖家中心的店铺共用这一个模板。
4. **店铺映射**：点「从紫鸟读取店铺」「加载中台店铺名单」，给每个紫鸟店铺选择模板、点「设置店铺」填写对应的中台店铺名、站点和 Shopee 店铺 ID。一个 CNSC 账号下有多个站点时，点「+ 添加站点店铺」逐个添加。勾选「启用」。

每个店铺可以先点「试采」：采集昨天的数据并只在中台试匹配，不写入，用来确认店铺名能对上。

## 三、日常使用

- **定时采集**：设置 → 定时采集，勾选「开启每天定时采集」，时刻建议 `09:30`（Shopee 前一天的数据在当地上午基本稳定），每次采集最近 3 天，旧数据会被新值覆盖。勾选「开机自动启动」后，电脑开机即在后台运行。
- **手动采集**：总览 →「开始采集」，可以选日期区间（补历史数据最多 62 天）。
- **查看结果**：采集记录里能看到每个店铺的成功/失败原因、每一行数据、中台返回的提醒。中台当时连不上时，可以在详情里「重新写入中台」。
- 关闭窗口不会退出程序（托盘里仍在运行，定时照常执行）；要退出请右键托盘图标 → 退出。

## 四、常见问题

| 现象 | 处理 |
| --- | --- |
| Shopee 卖家中心未登录 | 在紫鸟里手动打开该店铺，登录卖家中心后重试 |
| 要求安全验证 | 在紫鸟窗口里手动完成验证后重试 |
| 某个字段「未取到」 | 卖家中心可能改版，到「采集模板」重新校准一次 |
| 中台提示「已作为独立店铺记录」 | 店铺名和中台订单里的名称不一致：在店铺映射里改用下拉中的中台店铺名 |
| 页面脚本没有返回结果 | 紫鸟 CLI 版本与预期不同：设置 → 检查紫鸟环境，把提示截图给管理员 |
| 代理连接失败 | 程序会自动等 5 秒重试 3 次；仍失败请检查该店铺在紫鸟里的代理/IP |

数据和日志位置：`%APPDATA%\同舟智数\`（设置页「打开数据目录」）。模板可在「采集模板」导出，发到别的电脑导入即可复用。
