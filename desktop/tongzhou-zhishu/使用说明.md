# 同舟智数 使用说明

同舟智数会自动打开紫鸟里的 Shopee 店铺，读取每天的支付金额、订单数、访客、曝光、加购和广告花费，写入同舟供应链中台的「店铺日报」。只读数据，不改店铺任何设置。

## 第一次使用（约 1 分钟）

1. 这台电脑上的紫鸟客户端保持登录，Shopee 店铺在紫鸟里都已登录过卖家中心。
2. 双击 `同舟智数.exe`。
3. 在「总览」输入**中台账号和密码**，点「登录并连接」。账号需要有店铺日报（经营贡献分析 + 经营销售金额）权限。密码不保存。
4. 点「开始采集并写入中台」。完成。

程序会自动读取紫鸟里所有 Shopee 店铺、自动识别站点（印尼、马来……），并按店铺名自动对应中台店铺。

## 日常

- 在总览点「开启每天 09:30 自动采集」，以后每天自动采最近 3 天（Shopee 数据次日才稳定，旧数据会被新值覆盖），同时设为开机自启。关闭窗口后程序在托盘里继续运行。
- 「店铺」页可以看到每个店铺对应的中台店铺和上次结果；名字对不上的店铺，在下拉里选一下对应的中台店铺即可；不想采集的店铺取消勾选。
- 「采集记录」里能看到每次采到的数据和失败原因，中台当时连不上可以「重新写入中台」。

## 部署到多台电脑 / 云电脑

每台电脑上的同舟智数用中台账号登录后，会自动成为中台「工具与设置 → 采集中心」里的一个**采集节点**：

- 在采集中心能看到每个节点是否在线、紫鸟是否正常、负责哪些店铺、每次采集的结果和日志；
- 每天几点采集、采集最近几天，在采集中心统一修改，1 分钟内生效（节点上会显示「由中台采集中心管理」）；
- 可以在采集中心对某个节点「立即采集」、补采指定日期，或一键「重试」失败的店铺；
- 停用节点会让它立即失效，重新启用后在节点上重新登录一次中台即可。

云电脑只需要能访问中台网址，不需要开放端口。同一个店铺请只放在一台节点的紫鸟里采集，避免重复。

## 不用再人工核对

从 0.4.0 起，每个店铺采完后，程序会自动打开 Shopee 商业分析首页，切到「昨天 + 已付款订单」，把页面上显示的支付金额、订单数、访客数和采到的数字逐项比对，并截图留证（看完会把订单口径切回原来的选项）。

中台「采集中心 → 数据质量」每 20 分钟检查一次所有店铺最近 7 天的数据：
- 缺失、缺字段、和后台页面对不上、Shopee 还没出数 → **自动让负责的电脑补采**；
- 只有机器处理不了的（紫鸟账号未绑定设备、Shopee 掉登录、电脑离线等）才会列在「需要人工处理」里，并写清楚怎么处理；
- 点任意一格能看到当时的后台截图、页面数字和接口原始数据。

> 自己去 Shopee 后台对数时注意：商业分析默认显示的是「Placed / Confirmed Order」，日报用的是「Paid Order（已付款）」，要先切过去再对。

## 妙手排单定时（0.5.0 起）

每天按中台设置的时间，自动开启和关闭妙手「自动标记」里的排单规则（例如 OZON 排单 11:00–23:00、WB 排单 11:00–24:00，北京时间）。

1. 只需要在**一台常开的电脑**上做：打开「妙手排单」，点「登录妙手」，在弹出的妙手窗口里登录，然后关掉窗口。妙手密码只输入在妙手自己的页面里，本程序不读取、不保存。
2. 到中台「采集中心 → 妙手排单」，选择这台电脑作为执行节点，勾选要托管的规则，填开启 / 关闭时间，保存。
3. 之后不用管：程序每 2 分钟比对一次，到点 1 分钟内执行；电脑离线或妙手掉登录恢复后会自动补上。妙手登录失效时，中台「需要人工处理」会提醒，回到这里重新点一次「登录妙手」即可。

注意：托管中的规则如果在妙手里手动开关，会被程序改回来；要临时调整请用中台「妙手排单」里的「开 / 关」。

## 采集的数据口径

| 店铺日报字段 | Shopee 卖家中心来源 |
| --- | --- |
| 支付金额、订单数 | 商业分析 · 关键指标（已付款口径，按站点当地自然日） |
| 访客数 | 商业分析 · 关键指标「访客」（店铺页 + 商品页去重；0.4.0 之前误取了「店铺页访客」，会自动按新口径补采） |
| 曝光量 | 商业分析 · 流量来源「商品卡曝光」 |
| 加购数 | 商业分析 · 商品概览「加购人数」 |
| 站内广告花费 | Shopee 广告 · 商品广告 + Shop+ 广告 + 直播广告的花费 |

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 某店铺「Shopee 卖家中心未登录」 | 在紫鸟里打开这个店铺，登录卖家中心后重试 |
| 要求安全验证 | 在紫鸟窗口里手动完成验证后重试 |
| 店铺显示「未对上」 | 在「店铺」页下拉选择对应的中台店铺 |
| 数据取不到 | Shopee 卖家中心可能改版，联系管理员在「高级：采集模板」重新校准 |
